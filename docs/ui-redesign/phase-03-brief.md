# TrayPilot 界面重设计 · 第三部分（已确认）

前两部分已确认。本部分设计系统控件管理、兼容方案、识别中与连接失败状态，以及全部恢复确认。

## 信息架构

沿用固定导航与双主题。上方为连接状态、重新识别和方案选择；中间以控件卡片代替普通程序列表；右侧解释控件作用、保存行为与特殊限制。开关统一表示“显示图标”：开启显示，关闭隐藏；旁边保留具体状态文本。

分组：常用控件（音量、网络、电池、时钟）、状态提示（麦克风、定位、Studio Effects、Recall、通知铃铛）、任务栏（语言栏、附加图标、显示桌面）。共 12 项，与 `SystemIconCatalog.Items` 一致。

## 功能与状态

- 正常连接：显示当前识别数、已隐藏数、待出现后隐藏数；切换项目后自动保存。选择卡片可查看解释，开关可直接操作。
- 当前未出现：不当作识别错误；允许预设隐藏，状态变为“出现后自动隐藏”。不暗示该电脑一定支持或正在使用该控件。
- 正在保存：禁用重复提交和其他变更，保留当前状态与焦点，成功确认后再切换开关；失败则恢复原选择并显示明确错误，原型仅模拟成功路径。
- 正在识别：保留控件名称和已保存的选择；开关和恢复按钮暂不可用，使用状态文本与加载反馈，不展示虚假的进度百分比。
- 连接失败：保留选择、禁用状态操作，提供重试与方案选择；不因重试清空设置。诊断信息渐进展开，正式版本显示实际错误码。
- 新版兼容方案为默认推荐；首次使用或 Windows 更新后可能需要联网准备兼容资源。可尝试旧方案，切换后重新识别并应用保留的选择。
- 麦克风与定位：若识别到共享控件，单独隐藏其中一个时提示“共享图标待处理”，两者都隐藏才能隐藏共享提示；不把保存选择误报为图标已隐藏。
- 全部恢复：确认后恢复当前系统控件并清除全部系统隐藏选择，包括尚未出现的项目。普通软件图标与隐藏规则不受影响。
- 单项恢复：清除该项隐藏选择，与普通图标命中规则后的“本次暂时显示”不同。
- 普通自动隐藏规则的暂停不影响系统控件设置；退出时的系统恢复行为由后续设置页说明。

## 与原程序的关系

已核对 `LiveSystemIconsDialog.cs` 与 `SystemIconSession.cs`：系统选择使用独立位掩码，操作等待任务栏会话确认，失败回退；区分未找到、等待隐藏、已隐藏、可见、麦克风定位共享控件。当前程序只针对主任务栏。

原型模拟这些能力的 UI；全局恢复确认、可视化连接状态、控件卡片、撤销等是重新设计的交互，正式原生实现仍需连接现有后端。示例状态不代表本机实测结果，未实际改变任务栏。

系统项目用与原项目 `SystemIconImages.cs` 一致语义的线性图标示意，不用程序字母缩写。正式程序优先使用任务栏捕获的真实字形与外观，无有效外观时使用语义图形回退；时钟与语言栏的实际文本不固定为示例值。

## 视觉与可访问性

沿用已确认的色彩、间距与玻璃框架；控件卡片保持高不透明度。开关使用 switch 语义，独立标注“显示某图标”，暴露开关与禁用状态；卡片可通过键盘查看详情。模态窗口使用原生 dialog，支持 Escape 和焦点限制。错误状态通过文字、图形与 alert 反馈，减少动态效果时关闭旋转。

ui-ux-pro-max 的错误恢复、禁用重复提交和加载反馈指南已应用。“toggle state feedback”检索结果偏向移动触觉与导航，不适用桌面开关，未采用；改查“loading buttons”，获得适用的状态反馈建议。
