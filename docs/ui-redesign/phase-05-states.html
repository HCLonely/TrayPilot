欢迎使用 TrayPilot

给托盘留一点空间。

图标可以隐藏，软件照常运行。

01
先找到需要整理的图标

按名称或路径搜索，点击一行查看详情。

02
隐藏一次，或创建长期规则

双击切换状态；规则让图标再次出现时自动隐藏。

03
关闭窗口后，仍能从托盘打开

默认继续后台运行；结束运行请从托盘菜单退出。

结束微信进程？

微信WeChat.exe · PID 8048（示例）

这会关闭微信，未保存的内容可能丢失。再次打开微信后，托盘图标才可能重新出现。
