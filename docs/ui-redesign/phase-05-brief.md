# 第五部分：托盘快捷面板与完整操作状态（已确认）

五部分设计均已确认，设计方案已定稿。本部分完成设计范围的最后一组页面；正式界面的实现与 Windows 集成属于后续开发工作。

## 产品需求

主窗口收起后，用户仍可快速隐藏、恢复普通程序图标，暂停自动隐藏、调整开机启动、打开系统图标与设置。程序图标必须使用实际托盘图标或程序图标，不使用首字母。

托盘面板按程序路径分组；一个程序的多个图标可以分别操作，也可以全部操作。分组显示“可见”“已隐藏”“部分隐藏”，避免把部分隐藏误报为全部隐藏。恢复普通图标保留规则，也不修改系统图标选择。恢复命中规则的图标属于本次运行暂时显示。

面板固定宽度 380px，示例每页六个程序，共十二个程序；采用按钮、滚轮、方向键分页。正式程序现有菜单每页最多十组，实施时按屏幕可用高度确定容量，上限十组；不可将示例六项硬编码为后端限制。

## 操作状态

| 状态 | 呈现和下一步 |
| --- | --- |
| 首次使用 | 三步说明，可跳过，不强制创建规则 |
| 未识别到普通图标 | 刷新、启动具有托盘图标的程序，或转到系统图标 |
| 搜索无匹配 | 解释搜索范围，清空搜索 |
| 执行中 | 状态条、非确定进度；禁用重复执行，保留列表 |
| 部分失败 | 分开显示已完成与未完成数量，只重试未完成项 |
| 程序属性 | 当前程序的名称、路径、图标状态、规则和示例 PID，可复制 |
| 结束任务 | 显示对应图标和程序名，明确关闭进程及未保存内容风险；默认焦点为取消，提供“仅隐藏图标” |
| 退出 | 解释当前“退出时不恢复”偏好的影响，可取消 |

结束任务确认是新增的设计要求，现有正式程序尚未接入该确认界面。原型中的结束任务仅移除示例行，退出仅收起示例面板。
