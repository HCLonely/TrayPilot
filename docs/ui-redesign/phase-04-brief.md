# TrayPilot 界面重设计 · 第四部分（已确认）

前三部分已确认。本部分包含常规设置、外观与语言、全局快捷键，以及独立的关于与更新页。

## 信息架构与交互

- 设置内使用顶部标签分组，保留左侧全局导航；标签切换保留未保存修改。
- 常规：开机启动、显示自身托盘图标、关闭窗口后继续运行、退出后恢复图标。右侧同步展示行为预览，避免用户猜测关闭与退出的区别。
- 开机启动默认关闭；自身托盘图标与关闭到托盘默认开启；退出恢复默认关闭，与原项目默认值一致。
- 隐藏自身图标时，行为预览说明再次运行程序可唤回窗口，也可使用已启用的主界面快捷键。
- 关闭到托盘关闭后，窗口关闭即退出；文案与右侧预览随选择同步变化。退出恢复作用于普通软件图标与系统控件，关机或注销也遵循该设置。
- 外观：浅色 / 深色 / 跟随系统，采用小型窗口缩略图；选中后预览，保存后成为正式偏好，取消恢复旧外观。
- 语言：简体中文 / English；保存后正式版本应用语言包。原型保存语言选择，未连接原生语言包，不宣称已经完成整页翻译。
- 快捷键：打开主界面、显示所有图标、隐藏规则命中；默认全部关闭，预置 Ctrl+Alt+M / S / H。
- 提供按键录制与鼠标选键两种修改方式；至少包含 Ctrl 或 Alt，支持可见焦点、Escape 取消与 Tab 导航。原型选择器展示字母、数字、F1–F11，正式实现需兼容已保存的其他合法组合。
- 重复快捷键显示内联错误和可聚焦错误摘要；有冲突时阻止保存并保留草稿。原生保存仍需调用 RegisterHotKey 验证其他程序占用，失败回退；浏览器原型只能验证内部重复与组合格式。
- “显示所有图标”会暂停普通自动隐藏，并清除系统图标隐藏选择；“隐藏规则命中”继续普通规则并清除手动暂时显示例外，不重建已清除的系统选择。
- 底部固定保存区域：无修改时禁用保存 / 取消；修改后展示未保存状态；保存中禁用重复提交；离开设置或切到关于时出现未保存提醒。
- 关于：应用名称、版本、开发者、适用平台、项目主页、使用说明、问题反馈、发布记录与 Windhawk 致谢。
- 运行路径和设置文件夹放在渐进展开的诊断区；正式程序展示实际值，不在原型中暴露本机用户目录。

## 更新流程

检查仅由用户触发。状态包括尚未检查、检查中、无需更新、发现更新、失败、暂无正式发布版本。检查中禁用重复请求；失败提供重试。发现更新后前往 GitHub 发布页下载，不进行自动替换、安装或重启。

界面显示版本 1.4.1，来自本地 `app/TrayPilot.exe` 的 ProductVersion；并未联网查询最新发布。原型的更新结果为显式模拟状态，不代表 GitHub 当前实际状态。正式实现使用现有 UpdateChecker 及其超时、取消和版本比较行为。

## 与现有项目的关系

已核对 `ShellUi.cs`、`GlobalHotkey.cs`、`StartupRegistration.cs` 和 `UpdateChecker.cs`。原生设置现为统一保存与取消，快捷键注册、启动注册和设置持久化存在回退逻辑，本设计保留统一保存语义。

顶部分类、主题缩略预览、行为说明、未保存提醒和内联冲突呈现为新交互。原型不注册快捷键、不创建启动项、不写真实配置、不访问更新服务。

沿用 ui-ux-pro-max 的焦点、表单反馈与渐进展示基础原则。“progressive disclosure”检索及一次重试均仅返回标题排版，与本任务不符，未采用；“keyboard shortcuts”得到适用的键盘导航建议。关于诊断区折叠是结合桌面产品语境作出的设计判断。
