# TrayPilot 界面重设计 · 第一部分（已确认）

## 产品目标

帮助 Windows 用户看清托盘现状，快速隐藏不需要的图标，并明确区分一次性操作与长期自动规则。隐藏不会结束对应进程。

本轮提供设计原型，尚未连接原生程序。示例数据不代表当前电脑扫描结果。保留 WinForms 技术背景，最终落地方式在设计确认后评估。

## 功能需求

- 主导航只有图标管理、隐藏规则、系统图标三个工作入口；设置与关于置于底部。
- 主界面显示扫描到的普通图标数、可见数、隐藏数；这些计数不包含系统图标。
- 用搜索、全部/可见/已隐藏筛选降低定位成本。列表为默认布局，网格用于视觉浏览。
- 复选框明确多选；选择后出现批量操作。点击行打开详情，显示独立操作按钮；保留原程序双击切换的习惯。
- 列表将当前状态、规则范围、实际动作分别展示；隐藏项保留正常文字对比度。
- 详情包含进程、路径、规则来源；隐藏后显示撤销入口。完整路径可复制。
- 手动恢复命中规则的图标后，说明“本次运行暂时显示”，不暗示规则已删除。
- “全部恢复”仅恢复本工具隐藏的普通图标，保留规则，且不改变系统图标设置。
- 自动刷新与自动隐藏分开描述：关闭刷新不等于暂停规则。
- 属性和结束任务进入更多操作；结束任务必须有独立确认，不与隐藏按钮并列。

## 视觉规范

- 风格：克制的 Windows 桌面工具；玻璃效果集中于侧栏、窗口框架和叠层，列表采用高不透明度表面。
- 主题：雾白与石墨；蓝色为主要操作色；绿色仅代表运行状态。状态同时使用文字和图形。
- 字体：Segoe UI / Microsoft YaHei UI；正文 14–16 px，标题 28 px；路径采用等宽字体。
- 间距：4/8 px 基础节奏，内容边距 28 px，面板间距 20 px。
- 圆角：控件 8 px，内容面板 14 px，窗口 16 px；细描边与分层阴影。
- 图标：统一 1.7 px 描边 SVG；软件标识显示真实程序图标，保留原始颜色和比例；列表及网格为 32 px，详情为 40 px，不使用首字母缩写。正式程序优先使用实际托盘图标快照，无法读取时回退到对应可执行文件图标，最后使用通用程序图标。
- 色彩：亮色正文 #17243B、次级文字 #526178、强调 #2458D3；暗色正文 #EAF0FA、次级文字 #A6B4CA、强调 #9CBBFF。
- 可访问性：正常文字对比度至少 4.5:1；键盘焦点可见；图标按钮有名称；选中与状态不只依赖颜色；减少动态效果时关闭过渡。
- 默认设计窗口为桌面宽屏；小窗口折叠详情为抽屉，列表滚动；最终原生实现需验证 DPI 与系统字体缩放。

## 第一部分可检查内容

`phase-01.html` 为配套本地 assets、离线可打开的交互示意：主题切换、搜索筛选、列表/网格、选择详情、批量隐藏恢复、撤销均使用示例数据。其他导航入口提示后续设计阶段，不伪装为已完成页面。刷新仅反馈示例状态；原型不扫描电脑。

技能参考：已阅读 ui-ux-pro-max 的 SKILL.md、pro-rules.md 和 quick-reference.md。设计系统检索返回 Minimalism & Swiss Style，其 Hero + Features + CTA 为不适用的营销布局，未采用；单独检索到 Glassmorphism 风格，采纳其分层、磨砂、文字对比度原则。WinForms 不在技能支持的栈列表中，不将 WPF/WinUI 指南当作本项目实现方案。

验证：在 Edge 中检查搜索、空结果、筛选、临时恢复提示、撤销、批量操作、网格切换和 Ctrl/Shift 多选；检查 1020 / 1180 / 1440 px 桌面宽度无页面横向溢出。两套主题均已实际渲染并查看，详情主按钮始终可见。正文、次级文字和强调色对定义的不透明表面 token 最低对比分别为亮色 5.43:1、暗色 5.20:1；此值不替代原生程序最终合成与高 DPI 验证。

## 程序图标素材

OneDrive、微信、Steam、QQ、Everything 图标提取自本机已安装程序；Windows 安全中心图标提取自 SecurityHealthSystray.exe 资源。NVIDIA 与 Teams 使用各自官方网站的 favicon（https://www.nvidia.com/favicon.ico、https://teams.microsoft.com/favicon.ico）。素材仅用于本轮示意，正式界面采用实际扫描结果；主题切换与隐藏状态不修改品牌图标颜色。图标加载失败时提供通用程序图形，应用名称仍可辨识。
