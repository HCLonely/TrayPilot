## 产品目标与信息架构

用户需要看清当前托盘状态，把不常用图标隐藏，同时保持软件运行；对重复出现的图标建立自动隐藏规则。普通软件图标、系统图标和偏好设置各自承担清晰的管理范围。

## 视觉系统

采用克制的玻璃拟态：半透明窗框与侧栏、柔和环境渐变、薄描边、分层阴影；列表和文本区使用接近不透明的表面以保持可读性。模糊作为背景效果，程序图标与文字保持清晰。

| 主文字 | `#17243b` | `#eaf0fa` |
| 次文字 | `#526178` | `#a6b4ca` |
| 内容表面 | `#ffffffee` | `#1c2638f5` |

| 次级背景 | `#f1f5fa` | `#253247` |

主按钮背景始终采用 `#2458d3`，配白色文字。避免直接将深色主题的浅蓝文字令牌用作白字按钮背景。危险操作为红色文字或独立红色按钮，不与普通隐藏操作混用。

字体：Segoe UI、Microsoft YaHei UI，按系统回退。正文 13–14px，辅助信息 11–12px，页标题 28px，弹窗标题 21px。间距以 4px 为基础，常用 8/12/16/20/24/28px；按钮圆角 8px，卡片 14px，窗口 16px。主侧栏宽 196px，详情栏 272px；桌面布局缩小时允许列表滚动，避免缩小文字。

第一部分在不透明基底上检查的最小文本对比度约为浅色 5.43:1、深色 5.20:1；最终透明混合结果和原生渲染仍须复测。每个按钮具备悬停、按下、禁用和可见键盘焦点。状态始终有文字，不只依赖颜色；遵循减少动态效果偏好。

## 图标规范

优先使用实际托盘图标快照，其次使用对应程序图标，最后使用通用软件图标及不可用说明；不得使用首字母替代程序标识。程序图标按比例绘制，列表 32px、详情 40px、托盘面板 24px。界面操作图标采用同一线性图标风格，不以品牌图标替代操作语义。

原型中 OneDrive、微信、Windows 安全中心、Steam、QQ、Everything、Docker、Quicker、火绒和 Edge 的图片来自本机程序资源；NVIDIA 与 Teams 来自对应官方站点图标。它们是示例资产，正式程序应使用实时识别的实际图标，不能按程序名称硬编码品牌图片。

## 行为约定

- 隐藏：只改变图标显示，程序继续运行；自动隐藏需另建规则。
- 暂时显示：本次运行保留可见，原有规则保留。
- 恢复普通图标：仅恢复本工具管理的普通图标，保留规则与系统图标偏好。
- 暂停自动隐藏：保留规则和当前图标状态；继续时保留暂时显示例外。
- 应用隐藏规则：清除普通图标的暂时显示例外，重新执行规则。
- 显示全部快捷键：现有后端还会清除系统隐藏选择并暂停普通规则；说明必须准确，不能与恢复普通图标混称。
- 删除规则：只删除匹配规则；“同时恢复当前图标”单独选择，默认不勾选。
- 系统开关：开启表示显示；未出现的图标可预设隐藏，标注等待出现，不假装操作成功。
- 麦克风与定位：可能共享指示器，明确联动限制。
- 设置：草稿跨页签保留，保存时统一校验；失败保留草稿，取消恢复上次保存值。
- 快捷键：至少包含 Ctrl 或 Alt，禁止 F12，重复绑定先阻止保存；注册失败在正式程序中显示真实原因。
- 更新：手动检查并转到发布页下载，不承诺自动升级。
- 结束任务：确认真实目标，保留后端进程归属校验；系统 shell 和本程序不可结束。

## 原生实现边界

项目为 .NET 10 WinForms。图标扫描与资源使用 `TrayImages`；普通隐藏规则接续 `HiddenPaths`、`HiddenIcons`、`RulesPaused`；系统隐藏使用十二项独立掩码；常规刷新 2.5 秒、系统监听 5 秒。规则编辑、快捷键注册、设置保存与回滚继续使用既有业务逻辑，设计本身不要求切换技术栈。

原生落地时可采用自绘控件、缓冲绘制和适用的 Windows 窗口背景效果；系统不支持模糊或高对比度开启时使用不透明表面。保持实际图标透明边缘，验证 100/125/150/200% DPI、键盘与屏幕阅读器、主题切换、多显示器定位。主任务栏是当前支持范围，不宣称全部任务栏均可管理。

## 验证与交付

每部分均提供独立 HTML 原型、需求说明与亮暗 PNG。已完成浏览器交互检查、图标加载检查、布局溢出检查和截图复核。各页面使用独立示例数据，导航与评审主题已串联；刷新、保存、隐藏、更新检查和结束进程为设计模拟，无法证明 Windows 操作成功。新增危险操作确认、失败重试及细化状态，需要后续原生实现与集成验证。
